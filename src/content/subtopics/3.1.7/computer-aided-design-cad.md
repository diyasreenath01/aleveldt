<section class="note-panel"><h2>Digital design and manufacture</h2>
<div class="note-intro"><p>Digital design and manufacture uses computer hardware and dedicated software to design products and transfer design data directly to manufacturing equipment.</p>
<p>Simulation software is increasingly important as it allows manufacturers to plan, organise, predict, and optimise production processes before physical manufacture begins.</p>
<p>CAD is the use of computers to create 2D drawings and 3D computer models, stored in digital file formats that allow direct transfer to CAM equipment.</p></div>
<div class="note-grid"><div class="note-group-title"><h3>Computer aided design (CAD)</h3></div>
<div class="study-card"><h4>Advantages</h4>
<p>Faster design development due to editing, modification, and reuse of files</p>
<p>Higher accuracy and consistency than hand drawing due to computer calculations</p>
<p>Enables collaborative working across multiple locations via networked systems</p>
<p>Produces highly accurate files suitable for CNC machining and 3D printing</p></div>
<div class="study-card"><h4>Disadvantages</h4>
<p>High setup costs for hardware, software, and staff training</p>
<p>Requires ongoing updates and technical support</p>
<p>Less effective for quick, informal idea sketching</p></div>
<div class="study-card"><h3>Capabilities of 2D and 3D CAD software</h3>
<p>Photo-realistic rendering for presentation and client communication</p>
<p>Models can be rotated, sectioned, and viewed from any angle</p>
<p>Enables faster idea development compared with physical modelling</p>
<p>Existing artwork can be digitised and developed further</p>
<p>Editing tools (copy, mirror, rotate, scale) speed up iteration</p></div>
<div class="study-card"><h3>CAD/CAM file formats</h3>
<p><strong>DXF (Drawing Exchange Format)</strong> stores 2D vector data and is commonly used to transfer profiles for processes such as laser cutting, CNC routing and plotting.</p>
<p><strong>STL (Standard Tessellation Language)</strong> represents the surface of a 3D model as triangular facets. Smaller triangles give a more detailed surface but increase file size. STL files are commonly passed to slicing software before 3D printing.</p>
<p>Standard file formats improve compatibility between CAD software and manufacturing systems, allowing digital designs to move more easily from design to manufacture.</p></div>
<div class="study-card"><h3>Cloud-based CAD</h3>
<p>Cloud-based CAD allows design files to be accessed and shared online. It can support <strong>real-time collaboration, version control, cloud rendering and simulation</strong>, allowing teams in different locations to work on the same project.</p>
<p><strong>Advantages:</strong> easier collaboration, accessibility and reduced reliance on powerful local hardware. <strong>Limitations:</strong> internet dependency and data-security concerns.</p></div>
<div class="study-card"><h3>Industrial CAD features</h3>
<p>Libraries of standard components (e.g. electronics, hydraulics)</p>
<p>Layered 2D drawings showing structure, wiring, and casing</p>
<p>CAD/CAM simulations to predict machining strategies and errors</p></div></div></section>
